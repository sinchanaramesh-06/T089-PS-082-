# Evaluation readiness and limitations

## Output contract

The six CSV output files and their header order are asserted by `test_output_headers_match_evaluation_contract`. The implementation writes the required files using the published column sequences. Rows are generated by the command stream; registry snapshots are grouped and sorted by their grouping key, member accounts are sorted by member ID, and session results are emitted at session close.

## Validation performed in this package

Run:

```bash
python -m pytest -v
python -m carbon_exchange.cli --data data --output output
```

The test suite includes planted sample-pack checks, rule-level calculations, output header checks and a regression test for carbon-buffer streak reset on reversal.

## Not a guarantee of hidden-set success

No hidden input set or official expected output oracle is available to us. Passing local tests proves only the assertions in this repository. Before final submission, verify the evaluator's precise interpretations for ambiguous auction price discovery, carbon buffer fractional rounding, RPO carry-forward allocation, and reversal handling. Also compare complete output rows against any official expected outputs if they become available.
